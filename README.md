# Proyecto sobre 10 tipos de encriptaciones
En el presente proyecto veremos el funcionamiento de los distintos tipos
de encriptados 
El proyecto esta hecho en python 3.11
## INICIAR EL PROYECTO
Para iniciar el proyecto instale pyhton 3.11 o superior
para ver use:
```bash
    python --version
```
y  luego installe las dependencias con:
```bash
    pip install customtkinter
```
y ejecute el proyecto con: 
```bash
    python main.py
```
